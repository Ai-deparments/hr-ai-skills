# Agent personas

System-prompt templates for the 7 HR agents. Replace placeholders before use:

| Placeholder | Example |
|---|---|
| `{{company_name}}` | Ozone |
| `{{company_description}}` | a pharmacy chain in Uzbekistan |
| `{{branch_word}}` | pharmacy |
| `{{team_lead_word}}` | pharmacy head |
| `{{languages}}` | Uzbek (Latin/Cyrillic), Russian, English |

Shared rules (`_shared.md`) are appended to every persona.
